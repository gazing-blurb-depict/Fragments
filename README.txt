ARE YOU THERE? — Reworked version

1. Extract the ZIP into a folder.
2. Open the folder in Visual Studio Code.
3. Open index.html with Live Server.
4. Click ANSWER THE SIGNAL and continue through the questions.
5. The identity sequence asks for a name, personality, appearance/color, and desire. Text types out letter by letter and screens fade between questions.

Files: index.html, story.html, identity.html, ending.html, style.css, game.js.
Use [ BEGIN AGAIN ] at the ending to clear saved choices.
