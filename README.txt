ARE YOU THERE? — Interactive Story Game

FILES
- index.html: opening black-screen signal
- story.html: first dialogue and response choices
- identity.html: name and personality selection
- ending.html: personalized ending
- style.css: visual design, animation, responsive layout
- game.js: choices, story state, localStorage, navigation

HOW TO RUN IN VISUAL STUDIO CODE
1. Extract the ZIP to a folder.
2. Open that folder in Visual Studio Code (File > Open Folder).
3. Install the "Live Server" extension if you do not already have it.
4. Right-click index.html and choose "Open with Live Server".
5. Click through the story. Your choices are saved in the browser's localStorage.

HTML demonstrates page structure, semantic elements, links, buttons, labels, and inputs.
CSS demonstrates layout, responsive design, hover/focus states, and keyframe animation.
JavaScript demonstrates event listeners, conditionals, objects, page-specific behavior, and localStorage.

Note: The font is loaded from Google Fonts when you have an internet connection. If offline, it falls back to Courier New.
